Privacy Policy

Keb operates entirely on your machine. We do not collect, store, transmit, or share any personal data, browsing history, or usage information.

No Data Collection

Keb never sends data to any server we operate. All processing happens locally in your browser and on your own machine.

Self-Hosted Bridge

Keb connects to a local WebSocket server (ws://127.0.0.1:9876) that you run yourself. No third-party server is involved. You control all code and data.

No Analytics, No Tracking

There are no analytics SDKs, telemetry, cookies, or third-party services embedded in the extension or this website.

No Remote Code Execution

Keb does not fetch or execute remote scripts. The extension loads only its own bundled code. Your knowledge base is yours.

Third-Party Links

Keb may display links to external websites (e.g., saved URLs in your knowledge base). We are not responsible for the privacy practices of those sites.

Changes

If this policy changes, we will update the date below. Keb is open source — you can verify what the extension does by reviewing the code on GitHub.
